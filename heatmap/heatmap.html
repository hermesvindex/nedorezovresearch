Отраслевые эквиваленты показателей
  1. 1Выручка и банковский операционный доход. Для банков показан совокупный операционный доход, включающий чистый процентный, комиссионный и прочие операционные доходы; для страховщиков — страховая выручка, если она раскрыта источником. У девелоперов выручка признаётся по передаче объектов и не равна денежным продажам периода.
  2. 2EBITDA и маржа. Для банков показаны операционная прибыль до резервов и чистая процентная маржа NIM. Для страховщиков вместо EBITDA используется операционная прибыль. У авиакомпаний показатель зависит от учёта аренды по МСФО 16.
  3. 3Себестоимость. Для банков показаны операционные расходы. Процентные расходы уже учтены при расчёте чистого процентного дохода.
  4. 4Долг. Для банков показаны депозиты как основной источник фондирования. Это обязательства перед клиентами, а не корпоративный долг промышленной компании.
  5. 5Долг/EBITDA. Для банков показана достаточность общего капитала. Направление оценки различается: меньшая долговая нагрузка благоприятна для промышленной компании, более высокая достаточность капитала — для банка.
  6. 6Оборачиваемость активов. Для банков показан Cost-to-Income, CIR. У промышленной компании большее значение оборачиваемости обычно означает более эффективное использование активов; у банка меньшее значение CIR означает более высокую эффективность.
  7. 7FCF. Для банков и страховщиков стандартный свободный денежный поток неприменим. Их денежная генерация оценивается через прибыль, капитал, нормативы достаточности и дивидендный потенциал.
  8. 8EV/EBITDA. Для банков и страховщиков показатель неприменим; основными сравнительными мультипликаторами являются P/E и P/BV.
  9. 9Рентабельность. Для нефинансовых компаний рассчитывается как чистая прибыль / выручка. Для банков — как чистая прибыль / совокупный операционный доход.
  10. 10P/E. Капитализация / чистая прибыль. Показывает число годовых прибылей, заложенных в рыночной цене.
  11. 11P/BV. Капитализация / балансовый капитал. Показатель особенно значим для банков и других финансовых организаций.
  12. 12P/S. Капитализация / выручка. Для банков показатель экономически неприменим.
  13. 13ROE. Чистая прибыль / средний собственный капитал.
  14. 14ROA. Чистая прибыль / средние активы.

Обозначения: «—» — показатель отсутствует либо не прошёл контроль масштаба и экономической правдоподобности; «н/п» — показатель экономически неприменим к профилю компании.
