# Актуальные файлы

| Назначение | Файл | Статус |
|---|---|---|
| Входная витрина | `statements.html` | актуальный результат |
| Генератор | `build_statements.py` | канонический источник сборки |
| Индекс данных | `data/index.json` | локальная копия производного слоя |
| Данные эмитентов | `data/companies/*.json` | 217 файлов |
| Детальные страницы | `company.html?ticker=*` | 217 файлов, генерируются автоматически |
| Стили витрины | `assets/statements.css` | локальный визуальный слой |
| Логика витрины | `assets/statements.js` | поиск, фильтры, пагинация |
| Стили эмитента | `assets/company.css` | локальный визуальный слой |
| Логика эмитента | `assets/company.js` | фильтры, KPI, графики, таблицы |
| Результат сборки | `build_summary.json` | машинный контроль |
| Визуальная проверка | `design-qa.md`, `qa/*.png` | приемка desktop и mobile |

Файлы `company.html?ticker=*`, `build_summary.json` и локальные логотипы пересоздаются генератором. Ручное редактирование сгенерированных HTML не применяется.
