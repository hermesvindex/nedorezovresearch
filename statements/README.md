# Quantis Statements

## Назначение

Проект формирует автономную HTML-витрину финансовой отчетности эмитентов акций Московской биржи в дизайн-системе Quantis Design Lab.

Основной результат: `statements.html`. Детальная отчетность размещается в `company_pages/<TICKER>.html`.

## Состав данных

- 217 эмитентов;
- 546 589 нормализованных наблюдений;
- 16 секторов;
- период покрытия: 2000–2026 годы;
- стандарты: МСФО и РСБУ;
- типы периодов: годовые и квартальные.

Данные перенесены из производного слоя `library/reports`. Исходные CSV из каталога `smart` в проект не включены.

## Сборка

Из каталога проекта:

```bash
python3 build_statements.py
```

Через общий оркестратор Design Lab:

```bash
python3 ../generate_projects.py statements
```

Генератор создает:

- `statements.html`;
- 217 индексируемых страниц в `company_pages`;
- локальные копии 208 доступных логотипов;
- `build_summary.json` с результатами сборки.

При отсутствии локального логотипа интерфейс выводит текстовый тикер в качестве резервного состояния.

## Функциональный контракт

Входная витрина поддерживает поиск по названию, тикеру и ISIN, фильтры по стандарту и сектору, выбор числа строк и пагинацию.

Страница эмитента поддерживает:

- переключение МСФО и РСБУ;
- переключение годовых и квартальных данных;
- KPI с текущим значением, периодом и изменением год к году;
- сгруппированную столбчатую диаграмму выручки, EBITDA и чистой прибыли;
- график рентабельности EBITDA, чистой рентабельности и ROE;
- сравнение с восемью компаниями сектора по финансовым показателям, маржинальности и мультипликаторам;
- выделение текущего эмитента и расчет отклонения от медианы группы;
- выбор финансового показателя, столбчатую историю и таблицу изменений.

Для банков применяется отдельная модель: чистый операционный доход, чистый процентный доход, чистая прибыль, чистая процентная маржа, CIR и ROE.

## Ограничения данных

Дата версии производного слоя: 15 июля 2026 года. Качество и полнота отдельных показателей зависят от исходной отчетности и правил нормализации. Денежные показатели для отраслевого сравнения используют `normalized_value` в рублях. Витрина не выполняет конвертацию показателей, представленных в иной валюте. Первичные формы отчетности сохраняются как контрольный источник.
