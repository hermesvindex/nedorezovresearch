# Карта переноса пилота отчетности

| Элемент исходного проекта | Статус | Решение | Адаптация |
|---|---|---|---|
| `library/reports/index.json` | рабочий | перенесен | локальный индекс `data/index.json` |
| `library/reports/companies/*.json` | рабочий | перенесены | локальный слой из 217 файлов |
| `build_reports_library.py` | зависит от исходных CSV | не включен | проект использует готовый нормализованный слой |
| `build_heatmap_card_lab.py` | совмещает карту, карточки и отчетность | частично перенесен | логика отчетности выделена в `build_statements.py` |
| `company.html?ticker=*` | рабочий пилот | пересобраны | применены компоненты и токены Quantis Design Lab |
| CDN Plotly | внешний ресурс | исключен | используется `quantis_designlab/assets/vendor/plotly-2.35.2.min.js` |
| Логотипы data URI | увеличивают HTML | исключены | локальные файлы по ISIN |
| Фильтры МСФО/РСБУ | рабочие | сохранены | русские подписи и сегментированные контролы |
| Годовые/квартальные данные | рабочие | сохранены | адаптивная компоновка |
| KPI и мини-графики | недостаточный аналитический контур | переработаны | KPI с периодом и годовым изменением, без декоративных мини-графиков |
| Столбчатые финансовые диаграммы | отсутствовали в перенесенной версии | восстановлены | сгруппированные выручка, EBITDA и чистая прибыль |
| Рентабельность | была растворена в общем списке метрик | выделена | EBITDA margin, net margin и ROE с изменением в п.п. |
| Сравнение с отраслью | отсутствовало | добавлено | до восьми peers, медиана, выбор показателя, accent эмитента |
| Неправильные единицы процентов и ratios | исправлено ранее | правило сохранено | `%` и `x` выводятся отдельно от денежных единиц |
| Короткий fuzzy-match эмитентов | исправлено ранее | не используется | страницы строятся по точному тикеру локального индекса |
